# ai-dashboard

Terminal UI for tracking cutting-edge AI developments — a delta feed from arXiv, HackerNews, GitHub Trending, HuggingFace, and curated AI newsletters.

Built with Python 3.11+ and Textual. Full usage docs arrive in Phase 7.1 of the implementation plan.

See `.omc/specs/deep-interview-ai-news-tui.md` for the full specification and `.omc/plans/ai-news-tui-implementation.md` for the implementation plan.
